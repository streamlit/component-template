# Streamlit Component Template

## Components v2 (recommended)

```bash
uvx cookiecutter https://github.com/streamlit/component-template.git --directory=cookiecutter/v2
```

v2 is the current component API. See the [custom components overview](https://docs.streamlit.io/develop/concepts/custom-components/overview).

## Components v1 (legacy)

```bash
uvx cookiecutter https://github.com/streamlit/component-template.git --directory=cookiecutter/v1
```

v1 remains supported for existing components. New components should use v2.
